# Član 9.
(Ponovljivost)
(1) U postupcima ocjene usklađenosti utvrđuje se i ponovljivost predmetnog mjerila. Ponovljivost mjerenja etilometra je izražena kao eksperimentalna standardna devijacija za dati broj rezultata mjerenja.
(2) Eksperimentalna standardna devijacija data je slijedećom formulom:
Gdje je :
n = broj mjerenja dobivenih pri datoj masenoj koncentraciji,
Yi = i-to mjerenje (od n mjerenja) pri datoj masenoj koncentraciji,
Ῡ = aritmetička srednja vrijednost n mjerenja.
(3) Eksperimentalna standardna devijacija za sve masene koncentracije je manja ili jednaka jednoj trećini najveće dozvoljene greške.
