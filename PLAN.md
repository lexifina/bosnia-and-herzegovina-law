# The plan: every state-level source a lawyer or citizen of Bosnia and Herzegovina needs

This is the plan for this repository, part by part, with what is published so far. It is regenerated with each freshness commit, so the gap can be followed over time.

**51.3%** of the acts Službeni glasnik BiH lists in the planned kinds are on `main` (1,875 of 3,654); the rest are in [data/held.json](data/held.json), each with the rule that holds it. Updated 2026-11-11 09:05 UTC.
