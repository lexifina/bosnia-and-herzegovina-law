# Član 5.
(Program stručnog ispita)
(1) Program stručnog ispita za pripravnike, lica sa visokom školskom spremom i zaposlenike na nivou BiH (u daljnjem tekstu: Program) sadrži gradivo, pravne izvore i literaturu za svaki predmet iz člana 4. ove odluke.
(2) Program stručnog ispita propisuje ministar pravde BiH.
(3) Program stručnog ispita objavljuje se u "Službenom glasniku BiH".
