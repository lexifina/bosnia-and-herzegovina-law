# EVROPSKA KONVENCIJA O LJUDSKIM PRAVIMA Prava i slobode predviđeni u Evropskoj konvenciji za zaštitu ljudskih prava i osnovnih sloboda i u njenim protokolima se direktno primjenjuju u Bosni i Hercegovini. Ovi akti imaju prioritet nad svim ostalim zakonima.
