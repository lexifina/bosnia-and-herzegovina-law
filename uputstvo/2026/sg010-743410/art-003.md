# Član 3.
U članu 4. stav (1) mijenja se i glasi:
"(1) Zahtjev za prijavu prebivališta ili boravišta ili adrese stanovanja elektronskim putem, podnosi se putem web stranice nadležnog organa kod kojeg se vrši prijava prebivališta ili boravišta ili adrese stanovanja, unošenjem odgovarajućih kredencijala za kvalifikovani elektronski potpis."
U članu 4. dodaje se stav (3) koji glasi:
"(3) Zahtjev za izdavanje uvjerenja o činjenicama iz evidencija elektronskim putem podnosi se putem web stranice nadležnog organa prema mjestu prebivališta ili boravišta, unošenjem odgovarajućih kredencijala za kvalifikovani elektronski potpis."
